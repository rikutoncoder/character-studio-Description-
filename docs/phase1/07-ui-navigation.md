# PC・スマホの画面遷移と編集UI設計

## 共通原則

- PCとスマホで同じ制作機能を提供する。
- 同じレイアウトではなく、端末に適した配置にする。
- 約3分の生成中もマスク編集、履歴閲覧、別画面への移動を可能にする。
- AI生出力と厳密保持出力を明確に区別する。
- 採用操作では対象版と競合状態を表示する。
- タップ、マウス、トラックパッド、Apple PencilをPointer Eventへ統一する。

## 画面遷移

```text
端末ペアリング
  → プロジェクト一覧
  → プロジェクト概要
  → 編集画面
       ├── マスク編集
       ├── ガイド編集
       ├── 生成設定
       └── ジョブ進捗
  → 候補比較
       ├── 採用
       ├── 却下
       └── 再実行
  → 版履歴
       ├── 版詳細
       └── 過去版から新版作成
```

## PC編集画面

- 上部：プロジェクト名、現在版、保存状態、端末・ComfyUI状態
- 左：Asset、レイヤー、マスク、ガイド
- 中央：編集Canvas
- 右：ツール設定、ブラシ、フェザー、生成プリセット、prompt
- 下部：Undo/Redo、ズーム、ジョブキュー、版履歴への導線

Canvas上では保護領域、編集許可領域、ガイドを表示切替できる。マスク外を半透明保護色で示す表示モードを用意する。

## スマホ編集画面

- Canvasを主画面として最大化する。
- 下部ツールバーにブラシ、消去、パン、Undo、Redoを置く。
- レイヤー、生成設定、ジョブ、履歴はボトムシートで開く。
- ブラシサイズなど頻繁に使う設定は片手で操作可能にする。
- 二本指をパン・ズーム、一本指またはPencilを描画に使う。
- 誤採用防止のため、採用は比較画面から明示確認する。

スマホのブラウザがバックグラウンド化しても生成はサーバー側で継続する。復帰時にJob APIから状態を再取得する。

## マスク編集

- ブラシ、消去、全表示、マスク表示切替
- 画像ピクセル単位のブラシサイズ表示
- マスク面積とbounding boxの確認
- 空マスク警告
- 顔、髪、肌、手足、背景など保護対象の視認
- 内向きフェザーのプレビュー

フェザーのプレビュー表示と二値正本を混同しない。UIでぼけて見えても保存される正本マスクは二値である。

## 基準外サイズの案内

832×1216以外の画像を読み込んだ場合、元ファイルの保存と情報表示は行えるが、編集・生成ボタンを有効にしない。「Phase 1では832×1216のみ対応」と寸法を表示し、暗黙の拡大・縮小や切り抜きを行わない。

## ガイド編集

色変更プリセットでは仮着色ガイド、構造追加ではシルエットガイドを主導線にする。

- ガイド色の選択
- マスク内だけへの描画
- 形状の変形・消去
- 元画像、マスク、ガイドの重ね合わせ
- ガイドなし生成の場合の警告

## 生成設定

既定プリセット：

- `RECOLOR_GUIDED`: denoise 0.25〜0.35
- `STRUCTURE_ADD_GUIDED`: denoise 0.50〜0.65

通常利用では安全な範囲のスライダーまたはプリセットを提示する。詳細パラメータは折りたたみ、変更値はJobへ完全保存する。

## 比較画面

必須表示：

- 生成開始時の正本画像
- AI生出力
- 厳密保持出力
- 差分ヒートマップ
- マスク表示
- マスク外変更画素数
- 生成時間、seed、denoise、model、workflow revision

表示方式：

- 横並び
- Before/Afterスライダー
- ピクセル等倍拡大
- マスク境界だけの確認

Raw Outputには「直接採用不可」、Strict Outputには検証状態を表示する。

失敗または不採用Candidateには保存期限を表示し、残したいCandidateへ「保護」を設定できるようにする。ストレージ画面では、30日経過後に削除される件数、容量、予定日を確認できるようにする。

## 競合時UI

生成開始後に別端末が新版を採用した場合、古い候補へ「生成開始版が現在版ではありません」と表示する。採用ボタンを無効化し、最新版から再編集・再生成する導線を出す。

## 版履歴

- サムネイル、版番号、作成日時、操作種別を時系列表示
- 生成条件と親版を確認可能
- 過去版を選んでも即座に現在版を変更しない
- 「この版を基に新版を作成」の確認後に復元操作を実行
- 復元後も元の後続履歴を閲覧可能

## LAN接続とペアリング

1. Mac上で「端末を追加」を選ぶ。
2. 短時間有効のコードまたはQRを表示する。
3. スマホがLAN内URLへ接続してコードを入力する。
4. Mac側で端末名を確認する。
5. 端末セッションを発行する。
6. Mac側からいつでも失効できる。

ブルートフォース防止のため、コード有効期限、試行回数、再発行待ちを設ける。

認証済みスマホは最終利用から30日間ログイン状態を維持する。利用中は期限を更新し、30日間利用しなかった端末には再ペアリングを求める。Macの端末一覧には最終利用日時と解除操作を表示する。

スマホとMac間はHTTPSを必須とする。証明書が未設定または信頼されていない端末には、画像やペアリング画面を表示する前に、安全な接続設定の案内を表示する。

### 初回の証明書設定

1. Mac上でCharacter Studio専用の公開証明書と指紋を表示する。
2. スマホで公開証明書を取得する。
3. スマホのOS設定で証明書を信頼する。
4. Mac画面とスマホ画面の指紋が一致することを確認する。
5. HTTPS接続が成功してから、端末ペアリングへ進む。

秘密鍵はMac外へ出さない。証明書設定の解除方法と、Mac再セットアップ時の再登録手順も画面から案内する。

## アクセシビリティ

- 色だけでマスク・状態を区別しない。
- 操作ボタンに十分なタップ領域を持たせる。
- キーボード操作、フォーカス、ラベルを提供する。
- 生成状態をスクリーンリーダー向けlive regionで通知する。
- 重要な破棄・採用操作は確認と結果通知を行う。
