## Phase 0から引き継ぐ必須条件

- Animagine XL 3.1、832×1216、通常生成約3分を基準値とし、Phase 1の編集・生成解像度を832×1216に限定する。
- Mac M4・16GBでは生成処理を直列化し、同時実行数を1とする。
- AI生出力を確定版として直接採用しない。
- 各編集は直前の厳密保持済み確定版を入力にする。
- マスク外は元画像から画素単位で復元し、変更0画素を検証する。
- 色変更は精密マスク、仮着色ガイド、denoise 0.25〜0.35を基準とする。
- 構造追加はシルエットガイド、denoise 0.50〜0.65を基準とする。
- 同一seedの完全再現性は未証明であり、保証しない。
