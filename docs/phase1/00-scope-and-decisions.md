# スコープと設計判断

## 承認

本設計は2026-10-16にPhase 1実装基準として承認された。確定事項の変更は、理由・影響・移行方法を記録し、重要な変更について再承認を受ける。

## Phase 1の目的

次の制作フローを、PCと同一LAN内のスマホ実機から実行できるWebアプリとして成立させる。

1. 正本画像を読み込む。
2. 編集許可マスクを作成する。
3. 仮着色またはシルエットガイドを作成する。
4. ComfyUIへ生成を依頼する。
5. AI生出力へ厳密保持合成を適用する。
6. 元画像、AI生出力、厳密保持出力を比較する。
7. 候補を採用して新しい確定版を作る。
8. 版履歴から任意の過去版を基に新しい版を作る。

## 対象範囲

- 画像インポートと内部正本化
- プロジェクト、キャラクター、画像Asset、レイヤー、マスク、ガイド、版の管理
- マスクブラシ、消去、パン、ズーム、Undo/Redo
- 仮着色ガイドとシルエットガイド
- 色変更、構造追加の生成プリセット
- ComfyUI直列ジョブキュー
- キャンセル、失敗表示、再実行
- AI生出力と厳密保持出力の保存
- マスク外0画素の自動検証
- 三画像比較、差分表示、採用、却下
- 生成開始版と採用時最新版の競合検出
- 確定版の履歴と復元
- PCと同一LAN内スマホの同等編集機能
- 単一オーナー・複数端末とペアリング認証

## 対象外

- 三面図の生成
- Blender向け制作資料の出力
- 複数ユーザーの共同編集
- インターネット経由の外出先利用
- Supabaseなど外部サービスへの接続
- ComfyUIのインターネット公開
- AIによる自動マスク生成の必須化
- 同一seedの完全な画素再現保証
- 高ビット深度、CMYK、HDRの編集

## 確定した設計判断

### 技術構成

- Next.js / TypeScript
- Tailwind CSS
- React Konva
- Zustand
- Python / Pillow / NumPy
- SQLite＋Macファイルシステム
- Vitest / Playwright
- Supabaseは将来候補であり、Phase 1では導入しない。

### 利用形態

- 単一オーナーがPCと複数のスマホを利用する。
- 新しい端末はMac画面に表示する短時間有効のコードでペアリングする。
- 認証済み端末には失効可能なセッションを発行する。
- 同一LAN上でも未認証端末からAPIや画像へアクセスさせない。
- スマホとMac上のCharacter Studio間の通信はHTTPSで暗号化する。
- HTTP接続では画像、認証、編集APIを利用させず、HTTPSへの案内だけを返す。
- Mac上でCharacter Studio専用のローカル認証局とサーバー証明書を用意し、スマホへ初回だけ信頼設定を行う。
- 外部の証明書サービスや有料契約を前提にしない。
- 認証済み端末のセッションは最終利用から30日間有効とする。
- 有効な端末は利用時に期限を更新し、Macからいつでも個別に失効できる。

### 画像とマスク

- 内部正本は8bit sRGB PNGとする。
- Phase 1で編集・生成できる正本画像は832×1216に限定する。
- 別サイズの元ファイルはAssetとして保存できるが、自動変換せず編集対象外として案内する。
- RGBまたはRGBAをAssetメタデータに明記する。
- RGBA正本の透明情報は画像全体で元画像から保持し、Phase 1ではAIによる変更を許可しない。
- 元アップロードファイルと正規化後の正本を別Assetとして保存する。
- マスク正本は元画像と同寸法の二値PNGとする。
- フェザー幅はマスクとは別に保存し、編集領域の内側だけに適用する。

### 版管理

- 確定済み画像とAssetは不変とする。
- Undo/Redoと確定版履歴を分離する。
- 過去版の復元は、履歴を巻き戻さず新しい確定版を作成する。
- 採用時は生成開始時の版IDと現在の先頭版IDを比較する。
- 競合時は自動採用・自動画像マージを行わない。

### ComfyUIワークフロー

- Workflow JSONはGitで版管理する。
- 公開後のrevision内容を上書きせず、変更時は新しいrevisionを追加する。
- Jobにはworkflow revision ID、JSONファイルのSHA-256、実行パラメータのスナップショットを保存する。
- 過去Jobが参照するrevisionを削除しない。

### モデルファイルの識別

- モデルファイルは初回登録時にSHA-256を計算する。
- ファイル変更を検知した場合だけSHA-256を再計算する。
- 通常のJob開始時は、検証済みハッシュとファイル情報を照合する。
- 各JobAttemptへ、実行時に確認したモデル名とSHA-256を保存する。

### 保存期間

- 元画像、採用済み画像、そのMask・Guide・生成条件は自動削除しない。
- 失敗した生成画像と不採用Candidateは30日間保存する。
- ユーザーが「保護」したCandidateは自動削除しない。
- 自動削除前に対象件数と使用容量を確認できるようにする。

## 非機能要件

- 標準生成時間約3分を前提に、UIをブロックしない。
- ページ再読み込みやスマホの画面ロック後もジョブ状態を復元できる。
- ComfyUI停止時も確定版や編集中マスクを失わない。
- 保存AssetはSHA-256で整合性を検証できる。
- マスク外保持違反が1画素でもあれば採用不可とする。
- LAN外からCharacter Studioへ到達できる構成をPhase 1の既定にしない。
