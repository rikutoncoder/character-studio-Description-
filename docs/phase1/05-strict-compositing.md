# 厳密保持合成アルゴリズムと画素検証仕様

## 目的

ComfyUIのVAE往復で生じる編集対象外の微小差を、確定版へ一切持ち込まない。AIの編集精度とアプリケーションの保持保証を別に評価する。

## 入力

- `S`: 生成開始時の確定版正本。8bit sRGB RGB/RGBA PNG。
- `R`: AI生出力。正本と同寸法へ検証済み。
- `M`: 二値編集許可マスク。L PNG、0または255。
- `p`: 内向きフェザー幅。

`S`、`R`、`M`のwidthとheightが一致しない場合は合成しない。自動リサイズも禁止する。

## アルゴリズム

1. 全入力をデコードし、形式と寸法を検証する。
2. `M`が二値であることを検証する。
3. `M`内部だけで距離変換を行い、内向き係数`F`を作る。
4. 出力配列`O`を`S`のバイトコピーとして初期化する。
5. `M=255`の画素だけを処理対象にする。
6. フェザーなし領域では`R`をコピーする。
7. 境界領域では`F`を使って`S`と`R`を合成する。
8. `M=0`の画素は一度も演算・再代入しない。
9. PNGとして一時保存する。
10. 保存したPNGを再読込して画素検証する。
11. 合格時だけStrict Output Assetとして登録する。

概念式は次のとおりだが、マスク外は式を適用せず元配列のコピーを維持する。

```text
O(x,y) = S(x,y)                                 when M(x,y) = 0
O(x,y) = blend(S(x,y), R(x,y), F(x,y))          when M(x,y) = 255
```

## 色とアルファ

- マスク外のRGB/RGBAバイトは`S`をそのまま保持する。
- マスク内フェザーの色合成方式はsRGB上の単純補間と線形光補間を比較試験し、境界品質を確認して確定する。
- RGB正本へAI出力側のアルファを追加しない。
- RGBA正本ではアルファを画像全体で`S`からコピーし、マスク内外を問わず元値を保持する。
- AI出力のアルファは使用せず、透明領域の追加・削除をPhase 1では行わない。

## 必須画素検証

マスク外集合を`P = {pixel | M = 0}`とする。

```text
outside_changed_pixels = count(any(O[p,c] != S[p,c]) for p in P)
outside_max_delta = max(abs(O[p,c] - S[p,c]))
outside_mean_absolute_delta = mean(abs(O[p,c] - S[p,c]))
```

採用候補となる条件：

- `outside_changed_pixels == 0`
- `outside_max_delta == 0`
- `outside_mean_absolute_delta == 0.0`
- 寸法、チャンネル、色空間が期待値と一致
- RGBAの場合は全画素のalpha channelが元画像と一致
- 保存後ファイルの再読込でも同じ結果
- Asset SHA-256が記録済み

## AI生出力の診断値

Raw Outputについても同じ差分指標を計算するが、合否条件には使わない。Phase 0ではマスク外の約95〜98%に微小差が確認されているため、Raw Outputは比較・診断用に限定する。

マスク内については操作別の補助指標を持てる。

- 色変更：指定色優勢率、色差、白残り率
- 構造追加：暗色占有率、輪郭一致率
- 共通：マスク内平均差、境界帯の差分

これらは画質支援指標であり、自動採用条件にはしない。

## 失敗処理

- 1画素でも保持違反があれば`PIXEL_INTEGRITY_FAILED`とする。
- 失敗したStrict OutputをCandidateとして採用可能にしない。
- Raw Outputと診断値は原因調査用に保持できる。
- 同じ入力で自動的に無限再試行しない。
- デコード、寸法、色空間、保存後再読込のどの段階で失敗したかをエラーコード化する。

## 決定性

同じ`S`、`R`、`M`、合成実装バージョン、フェザー設定からは同一のStrict Outputを得ることを要求する。AI生成自体の同一seed完全再現性とは別の保証である。

合成実装バージョンをJobAttemptへ保存し、アルゴリズム変更後も過去結果を説明できるようにする。

## 境界テストケース

- 1ピクセルのマスク
- 画像端に接するマスク
- 穴を持つマスク
- 複数の分離領域
- feather 0、2、3、4px
- RGBとRGBA
- RGBAのマスク内外でalphaが元画像と完全一致
- 完全な黒・白・透明画素
- 空マスクと全面マスクの拒否
- 壊れたPNG、寸法不一致、非二値マスクの拒否
